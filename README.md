# دُرّة — DURRA · دار المجوهرات الفاخرة

متجر إلكتروني مصغّر وفاخر للمجوهرات، عربي يعمل من اليمين إلى اليسار (RTL)، ومستوحى في تجربته وأسلوبه من مواقع دور المجوهرات العالمية مثل بولغري (Bvlgari)، لكن بهوية تجارية مستقلة خاصة به. هو إعادة بناء كاملة لمشروع الطالب [`luxury_jewelry_store`](https://github.com/36p8/luxury_jewelry_store) الذي كُتب بـ PHP وMySQL. استُبدلت علامته السابقة بهوية مستقلة جديدة اسمها «دُرّة»، مستوحاة من تراث الغوص على اللؤلؤ في الخليج، وتحوّل إلى تطبيق ويب حديث متكامل فيه خادم وقاعدة بيانات ولوحة تحكم.

> للحصول على دليل تشغيل تفاعلي نفّذ: `bash README.sh help`

## المزايا

**للزوار والعملاء:**

- **الصفحة الرئيسية** (`/`): واجهة افتتاحية، ومجموعات مميزة، وتصنيفات، وقصة الدار.
- **الكتالوج** (`/collections`): المنتجات تُقرأ من قاعدة البيانات، مع تصفية حسب التصنيف (خواتم، عقود، أساور، أقراط) وبحث وترتيب حسب السعر.
- **صفحة المنتج** (`/product/:slug`): معرض صور ووصف ومواصفات (المعدن، العيار، الأحجار)، واختيار اللون، وأزرار الإضافة إلى السلة والمفضلة.
- **سلة التسوق** (`/cart`): السلة محفوظة لكل مستخدم، ويمكن تعديل الكميات فيها وحساب الإجمالي.
- **إتمام الطلب** (`/checkout`): إدخال عنوان الشحن، والدفع عند الاستلام، والشحن مجاني. بعدها تظهر صفحة تأكيد الطلب.
- **المفضلة** (`/favorites`): قائمة محفوظة لكل مستخدم، ويمكن نقل أي قطعة منها إلى السلة.
- **حسابي** (`/account`): سجل الطلبات مع خط زمني لحالة كل طلب.
- **صفحات المحتوى**: من نحن (`/about`)، والمعرض (`/gallery`)، وتواصل معنا (`/contact`). رسائل نموذج التواصل تُحفظ في قاعدة البيانات.

**لمالك المتجر:**

- **لوحة التحكم** (`/admin`): إحصاءات مختصرة ورسم بياني، وإدارة المنتجات (إضافة وتعديل وحذف ورفع صور حتى 8 ميغابايت)، وتحديث حالة الطلبات، وقراءة رسائل التواصل.
- **الإشعارات**: يصل إشعار تلقائي إلى المالك عند كل طلب جديد أو رسالة تواصل جديدة. إذا تعذّر إرسال الإشعار فلن يفشل الطلب أو الرسالة.
- **الصلاحيات**: المالك يحصل على صلاحية المسؤول تلقائياً عند أول تسجيل دخول. السلة والمفضلة والطلبات تتطلب تسجيل الدخول.

## التقنيات

| الطبقة | التقنيات |
| --- | --- |
| الواجهة | React 19، Vite، Tailwind CSS 4، shadcn/ui، wouter، framer-motion، recharts، sonner |

## التشغيل

### المتطلبات

- Node.js 20 أو أحدث، وpnpm 10 (`corepack enable`).
- قاعدة بيانات MySQL 8 أو TiDB متوافقة.

### متغيرات البيئة

أنشئ ملف `.env` في جذر المشروع:

```env
DATABASE_URL=mysql://user:password@localhost:3306/durra
PORT=3000
MANUS_JWT_SECRET=سلسلة-سرية-طويلة
MANUS_PROJECT_ID=...
MANUS_OAUTH_API_URL=...
MANUS_API_URL=...
MANUS_API_KEY=...
OWNER_OPEN_ID=...
```

داخل منصة Manus تُضبط هذه المتغيرات تلقائياً. تسجيل الدخول والإشعارات وتخزين الصور تعتمد على خدمات المنصة، أما خارجها فيعمل الكتالوج والصفحات العامة فقط.

### الخطوات

```bash
pnpm install                 # تثبيت الاعتماديات
pnpm db:migrate              # تطبيق ترحيلات قاعدة البيانات
pnpm tsx scripts/seed.ts     # بذر المنتجات (يضيف فقط القطع غير الموجودة)
pnpm dev                     # خادم التطوير على http://localhost:3000
```

أو باستخدام السكربت: `bash README.sh setup` ثم `bash README.sh dev`.

### الإنتاج

```bash
pnpm build && pnpm start     # يبني الواجهة في dist/public والخادم في dist/index.js
# أو عبر Docker
docker build -t durra . && docker run -p 3000:3000 --env-file .env durra
```

### الفحص

```bash
pnpm check    # فحص الأنواع
pnpm test     # تشغيل الاختبارات
```
